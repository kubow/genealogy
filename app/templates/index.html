How to use the tree

Graph navigation

Single click a person
Select them — shows their card in the right panel without moving the tree.
Double-click a person
Refocus the tree on that person (redraws ancestors & descendants around them).
Click a diamond ◊
Open the marriage/couple view: both spouses are highlighted and shown side by side.
Full tree button
Toggle between the focused view (ancestors + descendants of the current person) and the full connected tree.
Scroll / pinch
Zoom the graph. Click and drag to pan.

Person card (right panel)

Father / Mother chips
Click to select that person's card without moving the tree.
Spouse chip
Click to open the marriage view for that couple.
Children chips + branch button
The chip selects the child; branch highlights the path from root to that child in the tree.
Focus tree here
Redraws the tree centred on the person shown in the card.
✎ pencil button
Opens the edit forms below the card. Click Close edit to hide them again.

Left sidebar

Search
Filters the Focus person dropdown by name, place, or ID.
Branch dropdown
Highlight the path to a specific descendant.
Linked events review
Switches to a flat event list for reviewing sources and links.

Node colours

Yellow border
Current focus person (tree is centred here).
Orange border / background
Node is on the highlighted branch path.
Blue border / background
Couple mode — both spouses of the active marriage.
